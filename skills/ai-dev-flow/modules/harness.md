# 给项目搭 harness

项目自带的验证能力是最值钱的资产。没有它，"自走"不成立，每次合并都要问人。

## 1. 什么时候做

第一次进项目、`AGENTS.md` 没写 verify；某个改动没法被现有 verify 证明（补 verify 算这项的一部分）；复盘发现某类问题反复漏掉。只加脚本、样例、文档的是自走档；装软件、改系统设置、加远程是单向门。

## 2. 最低要求（升 L1 之前要有）

1. **verify**：一条命令（如 `scripts/verify.ps1`、`npm run verify`），含格式化、类型检查、lint、单测和关键回归，退出码 0 才算过，失败时打出能定位的信息。目标几分钟内跑完；超过 10 分钟排一项"快检提速"（项目可在 `AGENTS.md` 写"快检提速阈值：<分钟> 分钟"）。提速先量出最慢的测试下手，互不依赖的并行，覆盖的检查一项不减。快检里加 `pwsh -NoProfile -File <skill>/scripts/check-md.ps1 -Repo .`（查 `.md` 里的控制字符和被拆断的表格行）。
2. **改了哪里跑哪些**：快检超过 2 分钟的，在 `AGENTS.md` 写一张对照表（路径或模式 → 测试命令，最后一行"其他 → 全量"），总览 `projects.json` 给它配 `"trunkVerify": "<全量命令>"`（要装依赖的加 `"trunkSetup"`）。之后合并前只跑对照表选出的测试，全量由 `scripts/trunk-check.ps1` 在本机后台跑：`watch.ps1` 每 15 分钟拉起它，主干变了先记待跑，连续空闲 30 分钟、夜里 2–6 点或超过 24 小时没跑才跑最新那棵树，低优先级，全机一次一个；失败里只有超时的算机器忙、不记红；真红写 `.agents/trunk-red.json`，`/next` 开场先修。项目的 `.agents/` 要被 Git 忽略；快检要用没入库的文件的，`trunkSetup` 里复制进干净 worktree。
3. **verify:full（慢）**：e2e、真实宿主软件，可以慢但必须无人值守。独占资源的做成队列（第 5 节）。实际跑在服务器上的部分，用暂存环境实跑一单做冒烟，步骤写在项目自己的文档里。
4. **能操作产品**：Web 用 Playwright 加截图；桌面应用或宿主插件用一个 CLI 启动、驱动、抓日志和截图；数据处理用样例输入对比期望输出；调模型的功能用固定评测集，一条命令出分数和费用。
5. **北极星**：一个能看出离目标还有多远的数，量最终交付物，口径写进 `AGENTS.md`（`direction.md` 第 3 节）。
6. **`AGENTS.md` 是目录**，100 行以内：verify 命令、对照表、信任等级、北极星、单向门补充、禁止项、文档入口。长内容移到 `docs/`。规则多写"要达到什么、怎么量、哪些不能碰"，少写具体做法。
7. **空的 `LESSONS.md`**，头部两行 `reviewed-through: <当前主干 sha>`、`reviewed-on: <今天>`。
8. **`.agents/` 写进 `.gitignore`**；原始输出放 `.agents/evidence/`。
9. **verify 能并行跑**：几个 worktree 同时跑不互相破坏；共用缓存加进程间锁，只认构建成功后写的完成标记。

## 3. hooks

只放零例外的规则，个位数，写在项目里（Claude Code 用 `.claude/settings.json`）：结束前跑 verify 最快的部分；拦写受保护路径和越过单向门的命令（如 push）；提交前扫描密钥和本机绝对路径。每个 hook 写好后实际触发一次。

## 4. 权限：给够权限，底线交给脚本

- 碰外部软件、设备、真实数据的操作只走几个固定入口脚本，脚本内部守底线（独立实例、只处理副本、不接管用户在用的软件、退出前不保存）。
- 底线由脚本和 hook 守住的项目，agent 可以完全访问、不逐条审批；还用沙箱的按命令前缀放行。push、删除、改配置不进放行规则。改用户级权限是安全设置，用户同意才改。
- 同一类操作反复弹审批，收进脚本或放行规则。

## 5. 慢验证做成队列

适用于宿主软件、设备、GPU、付费接口：候选进队，N 个隔离工位，每次在独立临时目录跑副本。N 靠实测（并行结果和串行逐字段一致的最小吞吐拐点）。不接管用户在用的实例。单项超过 15 分钟的先加快速模式。

## 6. 完成标准

- [ ] 干净 checkout 上 verify 通过；亲手改坏一处，verify 变红
- [ ] 每个 hook 实际触发过一次
- [ ] `AGENTS.md` 写了 verify、北极星和信任等级
- [ ] 告诉用户：现在哪些事机器能自己证明，哪些还要人看
